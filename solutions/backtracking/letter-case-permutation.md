# 字母大小写排列 Letter Case Permutation

原题：[LeetCode 784](https://leetcode.com/problems/letter-case-permutation/)。以下是自行撰写的简述，完整约束以原题为准。

字符串只包含 ASCII 英文字母和数字。每个字母可以保留或切换大小写，数字保持不变，输出所有结果。本实现允许空串，产生一个空字符串；null 或其他字符拒绝。

## 思路

用字符数组表示当前状态。处理到位置 index 时，先保持该字符继续向后；若它是英文字母，再切换大小写，递归一次并恢复。

数字只有一个分支。英文字母才可使用 ASCII 的大小写位差进行切换，不能对任意字符直接做异或。每次到达末尾时构造新的字符串。

## 实现与复杂度

令 n 为字符串长度，L 为其中字母数。时间 O(n × 2^L)，包含构造输出字符串；辅助空间 O(n)，输出空间 O(n × 2^L)。空串单独为 O(1)。

## 边界与验证

- 纯数字只能得到原串，不能复制为多个相同结果。
- 大写、小写、数字交替出现。
- 空串、多次调用，以及非法输入。
- Java 测试对字母位置做位掩码枚举，对照完整结果集合并检查重复输出。
