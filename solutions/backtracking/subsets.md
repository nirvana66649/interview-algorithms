# 子集 Subsets

原题：[LeetCode 78](https://leetcode.com/problems/subsets/)。以下是自行撰写的简述，完整约束以原题为准。

输入互不相同的整数，输出所有选取组合，元素在每个组合中保持输入顺序。本实现把空数组定义为只有一个空子集；null 输入拒绝。

## 思路

`path` 表示已选元素，`start` 表示下一个可选位置。每个递归节点的当前路径就是一个子集，先复制加入结果，再尝试后面的各个元素。选中位置 i 后只向 i 后面的部分递归，因此一个组合不会因为选择顺序不同而重复出现。

递归返回后删除刚加入的元素，恢复调用前的路径。结果必须保存路径副本，不能把仍在修改的同一个 List 反复加入。

令 n 为输入长度。时间 O(n × 2^n)，包含复制所有子集的成本；辅助空间 O(n)，包含路径与递归栈；输出空间 O(n × 2^n)。空输入单独为 O(1)。

## 边界与验证

- 空数组产生一个空子集。
- 单元素产生空子集和它自身。
- 负数不影响选取规则。
- 输入含重复值不符合本版本的前提，应另做 Subsets II。
- Java 测试将所有子集与位掩码枚举结果比较，同时检查重复输出及输入不变性。
